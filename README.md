🖼️ AI Style Generator

AI-powered platform for generating personalized looks and enhanced photos.

The project allows users to create unique AI-generated visuals, explore ready-made templates, and manage personalized content through a modern web interface.

⚙️ Features
🎨 AI image generation (prompt-based)
🧩 Ready-made templates system
👤 Guest (visitor) and authenticated user support
🌐 Built-in UI translation (i18n)
🔐 Authentication with role-based access (user / admin)
📦 Scalable Redux architecture (slices, selectors, thunks)
⚡ API-first architecture (frontend + Node.js backend)
🧠 Tech Stack
Frontend: Next.js (App Router), Redux Toolkit, Tailwind CSS v4
Backend: Node.js + Express
State Management: auth / visitor / technical separation
Architecture: modular, scalable, production-oriented
